🎮 Игры

HronixBot предлагает увлекательные игры для вашего сервера. Начните играть прямо в Discord!

Шахматы

Сыграйте в шахматы с другом или против бота

!chess start @username - Начать игру с пользователем
!chess move e2-e4 - Сделать ход (нотация: откуда-куда)
!chess board - Показать текущую доску
!chess resign - Сдаться
💡 Подсказка: Используйте шахматную нотацию (e2-e4, g1-f3). Бот поддерживает все стандартные правила шахмат!

👋 Приветственные сообщения

Настройте автоматические приветствия для новых участников вашего сервера.

Настройка приветствий

Настройте канал для приветственных сообщений и текст

!welcome channel #general - Установить канал для приветствий
!welcome message Добро пожаловать, {user}! 🎉 - Установить текст приветствия
!welcome test - Тестовое приветствие (проверить настройки)
!welcome disable - Отключить приветственные сообщения
🔄 Доступные переменные:
• {user} - упоминание пользователя
• {username} - имя пользователя
• {server} - название сервера
• {memberCount} - количество участников

Пример настройки

!welcome message 🎉 Добро пожаловать, {user}!
Ты {memberCount}-й участник нашего сервера {server}!
Прочитай правила и приятного общения! 🚀

🔧 Основные команды

!help - Показать список команд
!ping - Проверить скорость ответа бота
!info - Информация о боте
!support - Ссылка на сервер поддержки

🆘 Поддержка

Возникли проблемы или есть предложения? Присоединяйтесь к нашему серверу поддержки!

Сервер поддержки

1. Проверьте, есть ли у бота необходимые права
2. Убедитесь, что команда введена правильно
3. Попробуйте перезагрузить бота командой !restart (если есть права)
